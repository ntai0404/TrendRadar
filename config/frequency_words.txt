#                        Word Group Definition Section
# ───────────────────────────────────────────────────────────────
# Write the keywords you want to follow here.
# Each word group is separated by a blank line, and keywords within the same group have an "OR" relationship.
#
# ┌─────────────────────────────────────────────────────────────┐
# │                      Syntax Overview (Quick Reference)                      │
# └─────────────────────────────────────────────────────────────┘
#
# Keyword syntax:
#   keyword            Normal keyword, matches if the title contains it
#   /regex/            Regular expression match (automatically ignores case)
#   keyword => alias    Specify a display alias for the keyword
#   [group alias]          First line of the group, specifies an alias for the entire group
#   +keyword           Required word, all required words must match for a successful match
#   !keyword           Filter word, if matched, excludes the news (only for the current group)
#   @number             Limit the maximum number of items displayed for this group
#
# Display name priority:
#   1. Has group alias → displays group alias
#   2. No group alias → displays concatenated aliases of each line (connected by " / ")
#   3. No alias → displays the keyword itself
#
#
# ┌─────────────────────────────────────────────────────────────┐
# │                      Basic Usage (Recommended for Beginners)                      │
# └─────────────────────────────────────────────────────────────┘
#
# 1. Simplest: write the keyword directly
#    ────────────────────
#    Huawei
#
#    Effect: matches all news containing "Huawei"
#
#
# 2. Group multiple keywords together
#    ────────────────────
#    Huawei
#    HarmonyOS
#    Ren Zhengfei
#
#    Effect: Matches news containing "Huawei" or "HarmonyOS" or "Ren Zhengfei", uniformly displayed as "Huawei / HarmonyOS / Ren Zhengfei"
#
#
# 3. Name the phrase group (Recommended)
#    ────────────────────
#    [Huawei]
#    Huawei
#    HarmonyOS
#    Ren Zhengfei
#
#    Effect: Same as above, but the display name is "Huawei" (more concise)
#
#
# ┌─────────────────────────────────────────────────────────────┐
# │                      Advanced Usage (Optional)                         │
# └─────────────────────────────────────────────────────────────┘
#
# 4. Use regular expressions to match multiple words (done in one line)
#    ────────────────────
#    /Huawei|HarmonyOS|Ren Zhengfei/ => Huawei
#
#    Effect: Matches news containing "Huawei" or "HarmonyOS" or "Ren Zhengfei", displayed as "Huawei"
#    Explanation: Use | to separate multiple words inside /.../, and the display name follows =>
#
#    💡 Don't understand regex? Ask AI:
#       "Help me write a regular expression that matches text containing 'Huawei' or 'HarmonyOS' or 'Ren Zhengfei',
#        format requirement: /regex/ => display name"
#
#
# 5. Exact match for English words (avoid false matches)
#    ────────────────────
#    /\bAI\b/i => AI
#
#    Explanation: \b represents a word boundary, avoiding matching "AI" in "MAIL"
#          /i means case-insensitive, matching "ai", "AI", and "Ai"
#
#    💡 Don't understand regex? Ask AI:
#       "Help me write a regular expression that exactly matches the English word 'AI' (not matching AI in MAIL),
#        case-insensitive, format requirement: /regex/i => display name"
#
#
# 6. Exclude specific content
#    ────────────────────
#    [Apple Inc.]
#    Apple
#    !fruit
#    !orchard
#
#    Effect: Matches "Apple" but excludes news containing "fruit" or "orchard"
#    Explanation: Words starting with ! indicate "exclude"
#
#
# 7. Limit the number of displayed items
#    ────────────────────
#    [Tech News]
#    Tech
#    @5
#
#    Effect: Displays a maximum of 5 matched news items
#    Explanation: @number indicates the limit on the number of items
#
#
# 8. Must contain multiple words simultaneously
#    ────────────────────
#    +Apple
#    +launch event
#
#    Effect: Must contain both "Apple" and "launch event" to match
#    Explanation: Words starting with + indicate "must contain"
#
# ───────────────────────────────────────────────────────────────
