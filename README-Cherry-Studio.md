#TrendRadar × Cherry Studio Deployment Guide 🍒

> **Suitable for the crowd**: Users with zero programming foundation
> **Client**: Cherry Studio (free open source GUI client)

---

## 📥 Step 1: Download Cherry Studio

### Windows users

Visit the official website to download: https://cherry-ai.com/
Or download directly: [Cherry-Studio-Windows.exe](https://github.com/kangfenmao/cherry-studio/releases/latest)

### Mac users

Visit the official website to download: https://cherry-ai.com/
Or download directly: [Cherry-Studio-Mac.dmg](https://github.com/kangfenmao/cherry-studio/releases/latest)


---

## 📦 Step 2: Get the project code

Why do you need to get the project code?

The AI ​​analysis function needs to read the news data in the project to work. Whether you use GitHub Actions or Docker deployment, the news data generated by the crawler is saved in the project's output directory. Therefore, you need to obtain the complete project code (including data files) before configuring the MCP server.

Depending on your technical level, you can choose to obtain it in any of the following ways::

### Method 1: Git Clone (recommended for technical users)

If you are familiar with Git, you can clone the project using the following command:

```bash
git clone https://github.com/yourusername/yourprojectname.git
cd your project name
```

**advantage**:

- You can pull a command at any time to update the latest data locally (`git pull`)

### Method 2: Directly download the ZIP compressed package (recommended for beginners)


1. **Visit the GitHub project page**

   - Project link: `https://github.com/your username/your project name`

2. **Download the compressed package**

   - Click the green "Code" button
   - Select "Download ZIP"
   - Or visit directly: `https://github.com/yourusername/yourprojectname/archive/refs/heads/master.zip`


**Note**:

- The steps are a little cumbersome. To update the data later, you need to repeat the above steps and then overwrite the local data (output directory)

---

## 🚀 Step 3: Deploy MCP server with one click

### Windows users

1. **Double-click to run** `setup-windows.bat` in the project folder. If there is any problem, run `setup-windows-en.bat`
2. **Wait for installation to complete**
3. **Record the displayed configuration information** (command path and parameters)

### Mac users

1. **Open Terminal** (Search for "Terminal" in the launcher)
2. **Drag** `setup-mac.sh` in the project folder to the terminal window
3. **Press Enter**
4. **Record the displayed configuration information**

---

## 🔧 Step 4: Configure Cherry Studio

### 1. Open settings

Launch Cherry Studio and click the ⚙️ **Settings** button in the upper right corner

### 2. Add MCP server

Find on the settings page: **MCP** → click **Add**

### 3. Fill in the configuration (important!)

Fill in the information based on the information displayed in the installation script just now.

### 4. Save and activate

- Click the **Save** button
- Make sure the switch in the MCP server list is **ON** ✅

---

## ✅ Step 5: Verification is successful

### 1. Test connection

In the Cherry Studio dialog box enter:

```
Help me crawl the latest news
```

Or try other test commands:

```
Search news about "artificial intelligence" in the last 3 days
Find "Tesla" related reports in January 2025
Analyze the popularity trend of "iPhone"
```

**Tip**: When you say "last 3 days", AI will automatically calculate the date range and search.

### 2. Success sign

If the configuration is successful, the AI ​​will:

- ✅ Call TrendRadar tool
- ✅ Return real news data
- ✅ Display platform, title, ranking and other information

## 🎯 Advanced configuration

### HTTP mode (optional)

If remote access or multi-client sharing is required, HTTP mode can be used:

#### Windows

Double-click to run `start-http.bat`

#### Mac

```bash
./start-http.sh
```

Then configure it in Cherry Studio:

```
Type: streamableHttp
URL: http://localhost:3333/mcp
```
